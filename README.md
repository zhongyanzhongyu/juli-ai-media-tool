# 聚力AI音视频处理工具

聚力AI音视频处理工具是一款面向自媒体剪辑、音频素材整理、口播素材处理的本地桌面工具。

当前版本主要支持根据 SRT 字幕时间轴，对音频进行自动切割，并支持片段合并、关键词筛选、片段排除、词库导入导出等功能。

## 主要功能

- 基于 SRT 字幕时间轴切割音频
- 支持最小时长 / 最大时长自动合并片段
- 支持关键词查找相关片段
- 支持排除指定关键词片段
- 支持只保留指定关键词片段
- 支持本地 JSON 关键词词库
- 支持 TXT 关键词导入 / 导出
- 支持深色 / 浅色主题切换
- 支持本地运行，素材不上传

## 适用场景

- 口播音频切割
- 自媒体素材整理
- 按字幕拆分音频片段
- 批量筛选含指定关键词的片段
- 去除不想保留的口播片段
- 直播切片、课程音频、短视频素材整理

## 使用方式

1. 下载 Releases 中的压缩包
2. 解压到任意文件夹
3. 双击运行 `聚力AI音视频处理.exe`
4. 选择音频文件
5. 选择对应的 SRT 字幕文件
6. 设置最小时长和最大时长
7. 点击「重新生成」预览片段
8. 根据需要使用关键词筛选
9. 点击「开始切割」导出音频片段

## 文件说明

请不要单独移动 exe 文件。

软件目录中建议保留以下文件：

- `聚力AI音视频处理.exe`
- `ffmpeg.exe`
- `juli_ai_qrcode.png`
- `personal_qrcode.png`
- `group_qrcode.png`

如果右上角显示「切割组件缺失」，请检查 `ffmpeg.exe` 是否和软件在同一个目录。
